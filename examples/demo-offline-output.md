# 离线 demo 输出示例（`python -m scripts.demo_offline`）

> **这是什么**：`scripts/demo_offline` 的**真实输出**，用于在不联网、不花 token 的前提下演示完整流水线。
>
> **桩替换了什么**：只替换了 **LLM 客户端**与**搜索函数**（假 LLM 返回固定文本、假搜索返回 `example.com` 链接），其余全部走真实代码 —— 编排、**补研回边**、评审循环、来源汇总、可观测。
>
> **所以**：下面报告的**正文是占位内容**（假 LLM 写的），但**流程、执行日志、来源清单格式**都是真的。想要真实内容，配好 `.env` 后跑 `python main.py`。
>
> 复现：`python -m scripts.demo_offline`（需先按 README §3 建好 `.env`）

## 三、这份输出证明了什么

| 观察到 | 对应能力 |
|---|---|
| 日志里出现 `Planner` / `Researcher` / `Analyst` / `Writer` / `Critic` 五类角色 | 5 Agent 协作 |
| `补研轮次：1（上限 1）`、计划被追加了第 3 条 | **补研回边**（Analyst 报缺口 → Planner 追加 → 重新调研 → 复评） |
| `完成 2 项调研...累计 2 条来源` 然后 `完成 3 项...累计 3 条来源` | 并行调研 + 来源累计 |
| 报告末尾的「参考来源」 | 带引用来源（决策 007） |
| 每步都有 `[N ms]` 与时间戳、末尾有 token 汇总 | 可观测性（决策 009） |
| 全程 `0.0s`、`9 次调用` 但用的是假 LLM | 桩只替换 LLM/搜索，**其余是真代码** |
