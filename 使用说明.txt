================================================================
 ResearchSwarm 使用说明（Windows 桌面版）
================================================================

【0】功能
----------------------------------------------------------------
输入一个问题，由 Planner、Researcher、Analyst、Writer 和 Critic
五个角色完成拆解、检索、分析、写作和评审，输出带来源清单的报告。

发现信息缺口时可以追加一轮检索；Critic 最多要求重写 2 次。
检索失败会列在“调研失败项”中，报告末尾附参考来源。

【1】运行环境
----------------------------------------------------------------
· Windows 10 / 11（64 位）
· Microsoft Edge WebView2 Runtime（Windows 11 通常已安装）
· 真实调研需要模型 API Key 和搜索 API Key；演示模式不需要密钥

发布包有两种形式：

目录版：ResearchSwarm.exe 和 _internal 文件夹必须一起保留。
        解压整个压缩包，再双击 ResearchSwarm.exe。
        只复制 exe 会因缺少依赖而无法启动。

单文件版：只有一个 ResearchSwarm.exe，可以直接双击。
          启动时会先自解压，因此比目录版慢。

【2】启动
----------------------------------------------------------------
双击 ResearchSwarm.exe。程序没有代码签名，Windows 可能显示
SmartScreen 提示；确认发布包来源后，可选择“更多信息”→“仍要运行”。

程序只监听 127.0.0.1。若双击没有反应，先检查是否已有窗口在运行，
再查看日志：%LOCALAPPDATA%\ResearchSwarm\logs\desktop.log

【3】配置模型
----------------------------------------------------------------
DeepSeek 开放平台：
  https://platform.deepseek.com/
API Key 页面：
  https://platform.deepseek.com/api_keys
接口文档：
  https://api-docs.deepseek.com/zh-cn/

创建并复制自己的 Key，然后在 ResearchSwarm 中打开“设置”：

  API Key：sk-xxxx...
  Base URL：https://api.deepseek.com/v1
  模型：deepseek-chat

点击“保存”，再点击“验证”。显示“配置可用”后即可开始调研。
Key 只应通过官方页面创建和管理；如怀疑泄露，请在官方页面删除并重建。

其他提供 OpenAI 兼容接口的服务也可以使用，只需修改 Base URL 和模型名。

Key 保存在：%APPDATA%\ResearchSwarm\config.json
设置接口只返回掩码。Key 会用于所配置模型接口的鉴权，不要分享给他人。

【4】演示模式
----------------------------------------------------------------
打开“设置”，勾选“演示模式”，然后直接输入问题。

演示使用内置模拟数据，经过实际的编排、补研和评审流程：
· 不联网，不消耗 token
· 报告来源使用 example.com 示例地址
· 适合检查界面和流程，不代表真实调研结果

取消勾选后恢复真实调用。

【5】界面与历史
----------------------------------------------------------------
左栏：
· 执行时间线：各 Agent 的状态、耗时和 token 用量
· 统计：总耗时、总 tokens、模型调用次数
· 历史运行：点击记录可回看；可单条删除或全部清空

右栏：
· 研究报告：显示排版后的报告
· 调研失败项：列出没有完成的检索或提炼
· 参考来源：显示本次检索取得的链接
· 复制：复制报告到剪贴板
· 导出 MD：导出 Markdown 文件

历史保存在：%LOCALAPPDATA%\ResearchSwarm\runs.db
关闭或重启程序不会清空历史。删除操作需要确认，且不可恢复。

【6】常见问题
----------------------------------------------------------------
Q：窗口空白或提示缺少 WebView2？
A：安装或修复 Microsoft Edge WebView2 Runtime，然后重新启动。

Q：提示没有配置 API Key？
A：在设置中填写并保存 Key，或先开启演示模式。

Q：提示 401 / Unauthorized？
A：检查 Key 是否正确、是否已被删除，以及是否带有多余空格或换行。

Q：提示 402 / Insufficient Balance？
A：模型账户余额不足，请在服务商官方页面查看用量和余额。

Q：请求超时或连接失败？
A：检查网络和服务商状态，也可以用演示模式确认界面是否正常。

Q：目录版双击后无法启动？
A：确认 _internal 文件夹与 exe 位于同一目录，并且没有只复制 exe。

Q：出现“调研失败项”？
A：可能是搜索限流、网页抓取失败或网络波动。可以稍后重试；
   失败项会保留在结果中，不能视为已经完成调研。

Q：如何卸载？
A：删除程序目录，并按需删除以下本机数据：
   配置：%APPDATA%\ResearchSwarm\config.json
   历史：%LOCALAPPDATA%\ResearchSwarm\runs.db
   日志：%LOCALAPPDATA%\ResearchSwarm\logs\

【7】隐私与费用
----------------------------------------------------------------
· 历史、配置和日志默认保存在本机，发布包不包含作者的运行记录或密钥。
· 真实调研会把问题、检索请求和读取到的相关内容发送给所配置的搜索与
  模型服务，用于检索和生成报告。使用前请确认这些服务的数据政策。
· 演示模式不联网。
· 费用由搜索和模型服务商按其规则收取，界面中的 token 统计可用于核对用量。
· 来源清单帮助回查出处，但不保证来源或报告结论正确，重要信息需要人工核实。
