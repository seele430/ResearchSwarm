================================================================
 ResearchSwarm 使用说明（多 Agent 深度研究工具 · Windows 桌面版）
================================================================

【0】这是什么
----------------------------------------------------------------
输入一个问题，5 个 AI Agent 协作完成调研，输出一份带来源清单的研究报告。

  Planner(拆解问题) → Researcher(并行检索) → Analyst(分析)
        ↑                                        │
        └──── 发现信息缺口就回头再查一轮 ────────┘
                                                 ↓
                            Writer(撰写报告) ⇄ Critic(质量评审，最多打回重写 2 次)

特点：
  · 报告末尾附「参考来源」清单，链接来自检索接口，不由模型编造
  · 检索失败会如实列出「调研失败项」，不会假装成功
  · 全过程可视化：每个 Agent 的耗时与 token 用量都能看到


【1】运行前需要什么
----------------------------------------------------------------
1) Windows 10 / 11（64 位）
2) WebView2 运行时（Win11 自带；Win10 若提示缺失，去微软官网免费装一次
   "Microsoft Edge WebView2 Runtime"）
3) 一个属于你自己的大模型 API Key（获取方式见【3】）
   —— 也可以先用【6】演示模式，不需要 Key
4) ⚠️ 重要：不能只复制那一个 exe 文件！

   本程序以「文件夹」形式发布：ResearchSwarm.exe 必须和同目录下的 _internal
   文件夹放在一起才能运行。

   ✅ 正确用法：解压整个压缩包 → 双击里面的 ResearchSwarm.exe
   ❌ 错误用法：只把 ResearchSwarm.exe 拷出来单独发/单独运行 → 会报错起不来


【2】启动
----------------------------------------------------------------
1) 双击 ResearchSwarm.exe
2) 首次运行 Windows 可能提示「Windows 已保护你的电脑」（因为程序没有购买
   代码签名证书，这是正常现象）：
      点「更多信息」 → 「仍要运行」
3) 看到标题为「ResearchSwarm · 多 Agent 深度研究」的窗口就是启动成功

程序只在本机运行（监听 127.0.0.1），不会对外开端口，也不会把你的文件传出去。


【3】注册并获取你自己的 API Key（DeepSeek 官方，推荐）
----------------------------------------------------------------
① 打开 DeepSeek 开放平台（创建 Key 的页面）：
      https://platform.deepseek.com/api_keys

   相关官方链接：
      平台首页：      https://platform.deepseek.com/
      用量与充值：    https://platform.deepseek.com/usage
      官方接口文档：  https://api-docs.deepseek.com/zh-cn/

② 注册 / 登录账号（手机号或邮箱都可以）

③ 在左侧菜单进入「API keys」→ 点「创建 API key」→ 复制生成的 Key
      Key 形如：sk-xxxxxxxxxxxxxxxxxxxxxxxx
   ⚠️ Key 只在创建时完整显示一次，请立即保存好；
      如果怀疑泄露，可以在同一页面删除并重新创建。

④ 账户需要有余额才能调用（在「用量 / 充值」页面查看）。
   DeepSeek 的单价很低：本工具跑一次完整调研大约消耗几万 tokens，
   具体费用以 DeepSeek 官方定价为准（界面上能看到每次运行的真实 token 用量）。


【4】把 Key 填进本软件
----------------------------------------------------------------
1) 点窗口右上角的「设置」
2) 「API Key」一栏：粘贴你的 sk-xxxx...
3) 确认下面两项（默认值就是最常见的组合，用其他模型时才需要改）：
      Base URL：https://api.deepseek.com/v1
      模型：    deepseek-chat          （也可换成 deepseek-reasoner）
4) 点「保存」，再点「验证」
      → 出现「配置可用」说明 Key 能正常调用；否则看【8】常见问题
5) 回到顶部输入你的研究问题，按回车或点「开始调研」

关于安全：Key 只保存在你自己这台电脑上（%APPDATA%\ResearchSwarm\config.json），
界面里永远只显示掩码（例如 sk-a****z1234），程序不会回传明文，也没有任何上传。


【5】想用别家的模型（可选）
----------------------------------------------------------------
只要对方提供「OpenAI 兼容」接口，把 Base URL 和模型名改掉即可，例如：

  · 其他云厂商的 OpenAI 兼容端点（智谱 / 通义 / Kimi / 硅基流动等）
  · 本地部署：Base URL 填 http://127.0.0.1:11434/v1 （Ollama 默认端口）

本工具默认按 OpenAI 兼容协议调用，不需要改代码。


【6】不想配 Key？用「演示模式」
----------------------------------------------------------------
设置 → 勾选「演示模式」→ 直接输入问题即可。

  · 使用内置的模拟数据，完整跑通五个 Agent 的流程（含补研回边、评审重写）
  · 不联网、不消耗任何 token、不花一分钱
  · 报告里的来源会是示例地址（example.com）—— 这是刻意的，不是故障

取消勾选即恢复真实调用。适合：先把界面和流程看明白，或给别人演示。


【7】界面怎么看
----------------------------------------------------------------
左栏：
  · 执行时间线 —— 每个 Agent 的耗时与 token；出现橙色的「补研」表示触发了
    回头再查；出现「评审 → 打回重写」表示 Critic 要求重写
  · 统计磁贴 —— 总耗时 / 总 tokens / LLM 调用次数
  · 历史运行 —— 每次运行都会自动归档，点一下即可回看当时的报告；
    关闭再打开程序也不会丢
右栏：
  · 研究报告 —— 支持标题、列表、代码、链接的简单排版
  · 调研失败项 —— 哪些子任务没查到（如实列出）
  · 参考来源 —— 报告引用到的链接
  · 「复制」把报告复制到剪贴板；「导出 MD」下载 Markdown 文件


【8】常见问题
----------------------------------------------------------------
Q：启动后窗口一片空白，或提示需要 WebView2？
A：装一次「Microsoft Edge WebView2 Runtime」（微软官网免费），或把 Edge 更新到最新。

Q：提示「还没有配置 API Key」？
A：在设置里填 Key 并保存；或先勾选演示模式把流程跑通。

Q：提示 401 / Unauthorized？
A：Key 复制有误或已被删除。重新创建并粘贴，注意不要带多余空格或换行。

Q：提示 402 / Insufficient Balance？
A：账户余额不足，去 https://platform.deepseek.com/usage 充值。

Q：提示超时 / 连接失败？
A：检查网络（部分公司网、校园网会限制 api.deepseek.com）。
   可以先勾演示模式，确认软件本身是正常的。

Q：双击没反应、一闪而过？
A：两种常见原因：
   ① 程序已经在运行了（本程序限制单实例，看任务栏有没有已开的窗口）
   ② 只复制了 exe，没有带上 _internal 文件夹（见【1】第 4 条）
   排查日志：%LOCALAPPDATA%\ResearchSwarm\logs\desktop.log

Q：报告里出现「调研失败项」？
A：检索接口限流或网络波动导致，重跑一次通常即可；失败项会被如实列出。

Q：想清空历史或配置？
A：历史库：  %LOCALAPPDATA%\ResearchSwarm\runs.db
   配置文件：%APPDATA%\ResearchSwarm\config.json
   日志：    %LOCALAPPDATA%\ResearchSwarm\logs\
   删掉这些即可；卸载 = 删除程序文件夹 + 上面这几处。


【9】隐私与费用
----------------------------------------------------------------
· 你的 API Key 只保存在本机，本软件不包含、也不会转发任何人的 Key
· 运行时你的问题文本与检索到的内容会发送给你配置的模型服务商（用于生成报告），
  除此之外不发送任何数据
· 程序只监听 127.0.0.1（本机回环），不对局域网或公网提供服务
· 费用由模型服务商按 token 计费；界面「统计」里能看到每次运行的真实用量
